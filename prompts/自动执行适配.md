# 三份完整核心提示词的自动执行适配

本文件只适配交互和文件输出，不替代或删减任何核心提示词。

用户已经要求一次跑完：原文、新主题、赛道均已提供，不再问欢迎语、主题确认或素材确认。完成本阶段内部各步骤后连续往下执行；解构报告、素材简报、M1–M7、评分与人味自检全部保留在 report 字段，正文与可选标题分别进入独立字段，方便用户复制。不要把报告内容混进正文，也不要以“内部思考”代替原提示词要求交付的报告。

核心固定为：仿写优化版v2.0 → 公众号标题生成器v3 → 人味增强v2.1。所有赛道使用同一套核心；不同赛道完整读取各自参考标题和人设。不调用旧的数码仿写分支或旧精简提示词。人设提供身份、语气、读者、赛道表达约束；其中如带有旧的四步流程、离线规则或交互确认，不启动另一套流程，由当前三份核心和本阶段联网开关控制。

用户的主题、态度、写法优先。原文可以来自另一个主题，只借鉴结构和情绪节奏；禁止移植不相干事实或改题。用户填写账号定位时优先采用；未填写时沿用赛道人设。身份仅决定叙述声音，不能据此虚构真实履历、亲测或采访。

正文按核心要求800–1500字（程序按去除空白的字符计算），标题加正文最多1550字符。标题默认40个；输入有明确数量则依标题核心的10–60范围执行。标题必须兑现正文内容。

联网仅在仿写阶段实际执行，聚焦新主题，至少3条可追溯素材；找不到近30天材料时如实记录实际搜索和材料日期，不把旧信息伪装成新热点，不造来源。标题和人味阶段仅使用上一阶段已保存材料，不重新搜索。不能因资料不足改题。正文禁止“虽然没有确定消息，但……”一类消息式否定；必要事实范围说明保持简短、中性。

用户已给全输入就不等待确认。真实缺失必填信息、严重且无法修正的合规问题、工具不可用不得伪造成功，须明确报错。程序会保存现场；自动重试耗尽后由用户重试，不无限烧额度。
